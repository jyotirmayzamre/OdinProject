# The Odin Project - Full Stack JavaScript

A comprehensive collection of projects completed through The Odin Project's Foundations and Full Stack JavaScript curriculum. This repository chronicles my journey from HTML/CSS fundamentals to full-stack web development with Node.js, Express, React, and MongoDB.

## About

The Odin Project is a free, open-source curriculum for learning web development. This repository contains all projects from the Foundations path and the Full Stack JavaScript track, demonstrating progressive skill development in frontend and backend technologies.

## Projects

### Foundations

**HTML & CSS Fundamentals**
- **odin-recipes** - Recipe website practicing HTML structure and basic CSS
- **landing-page** - Responsive landing page with flexbox layout
- **rock-paper-scissors** - Classic game implementing JavaScript fundamentals
- **Etch-a-Sketch** - Interactive drawing board with DOM manipulation
- **Calculator** - Functional calculator with JavaScript operations
- **Sign-up-form** - Form design with validation and styling

### Intermediate HTML & CSS

- **admin-dashboard** - Dashboard layout using CSS Grid
- **user-interface** - UI component explorations
- **form-validation** - Client-side form validation with custom constraints

### JavaScript

**DOM Manipulation & OOP**
- **library** - Book library application with object-oriented design
- **tic-tac-toe** - Two-player game with modular JavaScript
- **restaurant-page** - Dynamic restaurant site built with webpack
- **todo** - Task management app with local storage
- **battleship** - Battleship game with test-driven development
- **weather-app** - Weather application consuming external APIs

**Advanced JavaScript & Data Structures**
- **recursion** - Exercises exploring recursive problem-solving
- **linked-list** - Linked list data structure implementation
- **hashmap** - Hash map data structure from scratch
- **bst** - Binary search tree implementation
- **knights-travail** - Knight's shortest path using graph algorithms

### React

- **cv-app** - CV/Resume builder with React components and state management
- **memory-card** - Memory game testing React hooks and effects
- **shopping-cart** - E-commerce cart with React Router and context
- **wheres-waldo** - Photo tagging game with Firebase integration

### Full Stack

**Node.js & Express**
- **message-board** - Message board with CRUD operations
- **inventory** - Inventory management system with Express and MongoDB
- **members-only** - Authentication and authorization with sessions
- **blog-api** - RESTful blog API with admin frontend
- **file-uploader** - File upload service with cloud storage
