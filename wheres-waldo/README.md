# PixelMatch 
This is a photo tagging game where the goal is to find all the given characters in the map (Odin Project curriculum)

## Built with

- React
- Typescript
- NodeJS

## Features
- Multiple maps for the user to choose
- Light/Dark mode
- Server-side stopwatch to track time taken
- Popup to alert where a character is found or not
- Smart leaderboard using UUIDs
